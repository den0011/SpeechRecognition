## SpeechRecognition (1.4 version)

Проект представляет собой десктопное приложение для распознавания речи с использованием Whisper.cpp, написанное на C++ с применением фреймворка Qt. Приложение позволяет конвертировать голос в текст как в реальном времени через микрофон, так и из существующих аудиофайлов.

### Ключевые возможности:

* Запись и распознавание голоса
* Запись речи с микрофона в реальном времени
* Автоматическое сохранение аудиофайлов в папку recordings
* Распознавание текста с использованием моделей Whisper
* Поддержка нескольких языков (русский, английский, немецкий и др.)

### Режим реального времени (⚡):

* Включается галочкой «⚡ Реальное время» под кнопкой записи (включён по умолчанию)
* Звук читается с микрофона напрямую и делится на фразы по паузам (~0.7 с тишины)
* Каждая фраза распознаётся сразу, не дожидаясь остановки записи; пока фраза не закончена, ниже текста показывается промежуточный вариант
* Для минимальной задержки положите `whisper-server.exe` (есть в архиве whisper-bin) рядом с `whisper-cli.exe`: модель загружается один раз и остаётся в памяти. Без него каждая фраза распознаётся через whisper-cli — заметно медленнее и без промежуточного текста
* Вся сессия сохраняется в папку recordings, как и в обычном режиме

### Работа с файлами:

* Загрузка и распознавание существующих аудиофайлов
* Поддержка различных форматов: WAV, MP3, M4A, FLAC, OGG
* Хранение истории записей и результатов распознавания

### Настройки и конфигурация:

* Интеграция с Whisper.cpp: Указание путей к исполняемым файлам и моделям
* Настройка аудио: Выбор микрофона, частоты дискретизации, битрейта
* Эквалайзер: Настройка частотных диапазонов для улучшения качества записи
* Пресеты: Сохранение и загрузка настроек для различных сценариев использования

### Технические особенности:

* Логирование: Детальное ведение логов с цветовой дифференциацией
* Визуализация: Индикация уровня звука в реальном времени
* Тестирование: Возможность тестовой записи и воспроизведения
* Автоматические проверки: Валидация наличия компонентов перед записью

### Диктовка в любую программу:

* Горячая клавиша (по умолчанию **Ctrl+Alt+D**, меняется в настройках) включает и выключает запись, даже когда окно программы свёрнуто
* С галочкой «⌨ Вставлять в активное окно» распознанный текст печатается туда, где стоит курсор: Word, браузер, мессенджер
* Текст вводится как с клавиатуры (буфер обмена не используется), кириллица работает при любой раскладке

### Работа с текстом:

* Кнопки «Копировать всё», «Сохранить в файл» (.txt) и «Очистить текст»
* Галочка «🕒 Время у фраз» — каждая фраза с новой строки с отметкой времени

### Качество распознавания:

* **Фильтр шума Silero VAD** (Настройки → Шумоподавление) — нейросеть отсекает шум и музыку, whisper меньше «выдумывает» текст. Модель (0.9 МБ) скачивается загрузчиком
* **Режим скорости**: «Быстро» — укороченное окно распознавания; «Точно» — перебор 5 вариантов (beam search), примерно на 25% медленнее. Выбранная модель больше не подменяется автоматически
* **Язык auto** — автоопределение языка, добавлен польский
* Если микрофон 4 секунды передаёт полную тишину, программа предупреждает и подсказывает, что проверить

### Автоматическая загрузка компонентов:

Меню **Файл → ⬇ Скачать Whisper и модели** (также предлагается при первом запуске, если компоненты не найдены):

* Скачивает последнюю сборку whisper.cpp для Windows (whisper-cli + whisper-server) с GitHub: для процессора, с OpenBLAS (обычно быстрее) или для видеокарт NVIDIA (CUDA 12 / 11.8, в разы быстрее)
* Скачивает выбранную модель с HuggingFace, в том числе сжатые: base-q5_1 (57 МБ, качество как у base), small-q5_1, medium-q5_0, large-v3-turbo-q5_0
* Скачивает модель фильтра шума Silero VAD
* Находит уже установленные компоненты при запуске, даже если пути в настройках устарели
* Показывает прогресс и скорость, загрузку можно отменить
* Устанавливает всё в папку `whisper.cpp` рядом с программой и сам прописывает пути в настройках
* Использует встроенные в Windows 10/11 `curl` и `tar`, библиотеки OpenSSL не нужны

### Частые ошибки и их решение:

#### Whisper не найден
* Укажите правильный путь к whisper-cli.exe в настройках
* Для Linux/Mac убедитесь, что файл имеет права на выполнение

#### Модель не найдена
* Скачайте модель с HuggingFace
* Укажите путь к .bin файлу в настройках

#### Проблемы с микрофоном
* Используйте "Настройка микрофона" для тестирования
* Проверьте разрешения доступа к микрофону в системе
* Убедитесь, что микрофон не используется другой программой

#### Низкое качество распознавания
* Используйте более качественную модель (ggml-small.bin или выше)
* Настройте эквалайзер для усиления речевых частот
* Уменьшите фоновый шум
